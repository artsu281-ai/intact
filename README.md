# Intact

Нативное, элегантное и быстрое приложение для меню-бара macOS: голосовой ввод по горячей клавише,
причёсывание текста и вопросы к ИИ. Распознавание — через приложение Gemini (Google) или локально через whisper.cpp.

**Приватность.** Движок распознавания выбирается для каждой клавиши. Локальный Whisper работает на самом Mac — звук
не покидает устройство. Распознавание Google идёт через приложение Gemini для Mac: Intact нажимает в нём кнопку
микрофона через Универсальный доступ macOS и забирает готовый текст, поэтому речь обрабатывается на серверах Google.
Пост-обработка (причёсывание, вопрос к ИИ, чат) тоже зависит от выбранного провайдера: с локальной моделью
(llama.cpp) наружу не уходит ничего; при выборе приложения Gemini распознанный текст, а в чате ещё и заметки,
напоминания и содержимое прикреплённых файлов передаются в Gemini.app и уходят на серверы Google. Такие разделы
помечены в интерфейсе значком «уходит в облако».

## Установка

1. Скачайте `Intact.zip` со страницы [Releases](https://github.com/artsu281-ai/intact/releases/latest), распакуйте и перенесите
   `Intact.app` в «Программы».
2. Приложение подписано локальным сертификатом, а не Apple. Если macOS не даёт его открыть: «Системные настройки →
   Конфиденциальность и безопасность → Всё равно открыть».
3. При первом запуске мастер настройки по шагам попросит микрофон, «Мониторинг ввода» и «Универсальный доступ» и
   предложит движок распознавания. Дальше Intact сам предлагает обновления (кнопка в меню).

## Особенности

- **Распознавание Google без ключей API**: Intact управляет диктовкой приложения Gemini через Универсальный доступ macOS. Если Gemini не вернул текст, сказанное дорасшифрует локальный Whisper по параллельной записи.
- **Локальный ИИ**: 6 моделей Whisper для речи и 17 текстовых моделей (llama.cpp) трёх весов — лёгкие от 8 ГБ памяти, крупные от 16 ГБ, очень крупные от 32 ГБ; скачиваются в один клик, фильтр «Только то, что влезет» в этот Mac.
- **Мастер первой настройки**: три шага — микрофон, клавиатура, распознавание; открывается и из меню.
- **Мгновенная вставка**: распознавание черновиков прямо во время речи с нулевой задержкой при отпускании клавиши.
- **Голосовые пайплайны**: своя клавиша (или кнопка мыши) под каждый сценарий — просто вставить, причесать текст перед вставкой или сразу спросить у ИИ и вставить ответ.
- **Голосовые команды**: «Заметка: …» и «Напомни …» кладут сказанное в Apple Notes / Reminders, «Джеминай, …» отправляет фразу в Gemini.app в фоне — окно не появляется на экране.
- **Чат и брифы**: полноценный чат с ИИ (с историей веток, прикреплением файлов) и автосводки надиктованного за день/неделю.
- **Интерфейс в стиле Wispr Flow**: тёплые органические оттенки, Serif-заголовки, плавные переключатели и карточки.
- **Управление звуком и плеерами**: автоматическое заглушение системного звука и пауза Apple Music / Spotify во время диктовки.
- **Проверка и обновление моделей**: автоматическая проверка актуальности моделей Whisper на Hugging Face в один клик.
- **Гибкая активация**: удержание любой клавиши (например, `⌥ Option`, `Fn`, `⌘ Command`) или глобальное сочетание клавиш.
- **Словарь терминов и перевод**: поддержка `initialPrompt` для точного распознавания специализированного сленга и возможность автоперевода на английский.

## Требования

- macOS 14+ (Sonoma, Sequoia), Apple Silicon
- Приложение [Gemini](https://gemini.google/) для Mac — для распознавания Google (рекомендуется)
- `brew install whisper-cpp` — локальный движок распознавания (запасной или основной без интернета)
- Модели ggml в `~/Models/whisper/` (скачиваются и обновляются прямо из вкладки «Модели»)
- Для пост-обработки — либо `llama-server` из `brew install llama.cpp` с локальной GGUF-моделью,
  либо установленное приложение [Gemini](https://gemini.google.com/) для Mac (опционально, не входит
  в состав Intact)

## Сборка из исходников

```bash
./build.sh
```

Скрипт собирает release-бинарник, упаковывает в `Intact.app`, подписывает локальным сертификатом (или ad-hoc) и устанавливает в `/Applications/Intact.app`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `IntactApp.swift` | Точка входа, строка меню (`MenuBarExtra`), активация, разрешения |
| `DictationController.swift` | Оркестрация жизненного цикла: запись → черновики → пост-обработка → вставка |
| `PipelineConfig.swift` | Модель голосового пайплайна (триггер → движок → действие), хранение, конфликты триггеров |
| `InputEventManager.swift` | Единый `CGEventTap` под клавиши и кнопки мыши всех пайплайнов |
| `ModifierKeyMonitor.swift` | Отслеживание удержания модификаторов (`⌥`, `⌘`, `⌃`, `⇧`) — легаси-путь для `hotKeyHold`/`hotKeyToggle` |
| `WhisperServer.swift` | Фоновый сервис `whisper-server` с загруженной моделью и HTTP API |
| `Transcriber.swift` | Резервный режим через `whisper-cli` |
| `AudioRecorder.swift` | AVAudioEngine, 16 кГц моно, расчёт RMS уровня громкости и срез WAV |
| `AIProvider.swift` | `AIRouter` — маршрутизация ролей (чат/причёсывание/быстрый ответ) между провайдерами |
| `LocalAIProvider.swift` | ИИ-провайдер поверх локального `llama-server` |
| `GeminiAIProvider.swift` / `GeminiBridgeService.swift` | ИИ-провайдер и голосовая команда «Джеминай» поверх приложения Gemini.app (Accessibility API) |
| `AIChatService.swift` | Логика чата: история веток, прикреплённые файлы, инструменты (веб-поиск, чтение страниц) |
| `Brief.swift` | Автосводки надиктованного за день/неделю |
| `AppleNotesService.swift` / `AppleRemindersService.swift` | Голосовые команды «Заметка…» и «Напомни…» |
| `MediaController.swift` | Заглушение системного звука и авто-пауза музыки во время речи |
| `ModelManager.swift` / `LLMModelManager.swift` | Каталог моделей Hugging Face, скачивание, проверка ETag и обновление |
| `TextInserter.swift` | Вставка через Accessibility API / ⌘V буфер обмена |
| `Settings.swift` | Постоянные настройки пользователя в UserDefaults |
| `History.swift` | Локальная история последних распознаваний |
| `Views/Theme.swift` | Дизайн-система: цвета Palette, стили свитчей WisprToggleStyle, типографика |
| `Views/SettingsView.swift` | Единая панель настроек с разделами Главная, Диктовка, История, Чат, Спросите ИИ, Брифы, Модели, Настройки |
| `Views/RecordingIndicator.swift` | Плавающий индикатор записи с живой звуковой волной |

## Разрешения macOS

1. **Микрофон** (`NSMicrophoneUsageDescription`) — для захвата голоса.
2. **Мониторинг ввода** (Input Monitoring) — для считывания зажатия клавиш и кнопок мыши, которые запускают пайплайны.
3. **Универсальный доступ** (Accessibility) — для вставки текста в фокусные поля приложений и (если используется) фонового управления Gemini.app.

При сбросе разрешений:
```bash
tccutil reset Accessibility com.artsu.intact
tccutil reset ListenEvent com.artsu.intact
```
